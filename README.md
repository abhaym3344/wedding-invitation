## 📦 Documentation

* Run the `npm install` command, then `npm run dev`, and open `http://localhost:8080`.
* Change the contents of the `index.html` file to your liking.
* If you do not want to use the **comment feature**, remove the `data-url` and `data-key` attributes in the `<body>` element of `index.html`.
* Adjust the `data-url` on the `<body>` in index according to your backend URL (if you are self-hosting).
* Set the `data-key` in index to the access key provided by your backend.
* If you want to use GIFs, get a Tenor API key at [developers.google.com/tenor](https://developers.google.com/tenor/guides/quickstart).
* For deployment, run `npm run build:public`. The `public` folder is the one you will upload.
* For backend self-hosting, see the explanation below, or use the **trial API** for free.

> This invitation only uses standard HTML, CSS, and JavaScript. NPM is used so that the JavaScript files can be executed directly (no longer as a module type).

> If you still want to proceed without NPM, change `src="./dist/guest.js"` to `src="./js/guest.js" type="module"` on the `<head>` tag in index.html, with the risk of theme glitches during initial loading.

> If you have any questions, use the `discussions` feature so that it can also be read by others.

> [!WARNING]
> Use version 3.14.0; version 4 is still in the development stage and potentially contains bugs 🐛
